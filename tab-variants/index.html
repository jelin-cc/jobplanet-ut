서브 필터 영역 리디자인 시안

헤더 아래 칩 4개를 다른 형식으로 바꾸고, 필터와 카드가 하나의 덩어리로 읽히도록 재구성했습니다.
탭을 눌러보면 카드가 실제로 전환됩니다.

현재

칩 + 회색 구분선

칩 줄과 카드 사이의 가로 전체 1px 라인이 두 영역을 잘라놓아, 필터와 결과가 별개 섹션으로 읽힘. 칩 테두리와 카드 테두리가 같은 회색이라 위계도 흐릿함.

시안 A

세그먼트 컨트롤 + 회색 패널로 묶기

칩을 세그먼트 컨트롤(하나의 트랙 안 4분할)로 바꾸고, 구분선을 지운 뒤 필터와 카드를 같은 연회색 패널 위에 올렸습니다. 카드는 흰색으로 띄워서 선택된 세그먼트(흰 알약)와 같은 톤 → 필터·결과가 한 세트로 보임.

시안 B

언더라인 탭 + 단일 카드 컨테이너

필터를 언더라인 탭으로 바꾸고, 전체를 테두리 1개짜리 컨테이너 안에 넣었습니다. 회색 선은 컨테이너 폭 안에서만 끝나 "탭의 밑줄"로 읽히고, 카드는 테두리를 빼고 연회색 면으로 처리해 컨테이너 안 내용물로 종속됩니다.

시안 C

연결형 탭 (선택 탭이 카드 면과 이어짐)

선택된 탭이 아래 패널과 같은 배경색으로 이어져 물리적으로 한 면이 됩니다. 어느 필터의 결과인지 시선으로 바로 연결되고, 구분선이 아예 필요 없어짐. 상단 검정 pill(1차 탭)과 위계도 자연스럽게 나뉨.
